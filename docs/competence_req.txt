# Competence Management Suite  
## Modular Plugin Architecture (21 Independent Plugins)

---

# Overview

This document defines a complete **Competence Management System** implemented as 21 independent but interoperable plugins.

Each plugin includes:

- Purpose
- Dependencies
- Menu Structure
- Settings
- Dashboard Requirements
- Detailed Functional Requirements

All plugins operate under the main navigation:

Competence Management

---

# 1. Skill Taxonomy Plugin

## Purpose
Central master registry for all skills and competencies.

## Dependencies
None (Foundation Plugin)

## Menu Structure
Competence Management  
└── Skill Taxonomy  
    ├── Skill Library  
    ├── Categories  
    ├── Framework Mapping  
    └── Import / Export  

## Settings
- Proficiency Scale Configuration (1–5, Custom)
- Enable Skill Versioning (Boolean)
- External Framework Mapping (SFIA, ESCO, O*NET)
- Skill Approval Workflow (Optional)

## Dashboard
- Total Active Skills
- Skills by Category
- Recently Added Skills
- Skill Usage Trend

## Functional Requirements
- Create / Edit / Archive skills
- Define parent-child relationships
- Assign metadata and tags
- Maintain skill versions
- Import/export skill library (CSV/JSON)
- Prevent hard deletion (soft delete only)

# 1️⃣ Competency Framework Plugin

## Purpose
Central library to define competencies, categories, and proficiency levels.

## Dependencies
None (Foundation Plugin)

## Menu Structure
Competence Management  
└── Framework  
  ├── Competency Library  
  ├── Categories  
  ├── Proficiency Levels  
  ├── Version History  
  └── Import / Export  

## Dashboard
- Total Competencies
- Competencies by Category
- Version Timeline
- Active vs Archived

## Settings
- Proficiency Scale (1–5 or Custom)
- Versioning Enabled
- Archive Policy

## MongoDB Schema

### Collection: competencies
```json
{
  "_id": "ObjectId",
  "code": "COMP-001",
  "name": "System Architecture",
  "description": "Design scalable systems",
  "categoryId": "ObjectId",
  "levels": [
    { "level": 1, "label": "Beginner" },
    { "level": 2, "label": "Intermediate" },
    { "level": 3, "label": "Advanced" },
    { "level": 4, "label": "Expert" }
  ],
  "version": 1,
  "status": "active",
  "createdAt": "ISODate",
  "updatedAt": "ISODate"
}
```
