# Resource Management

Overview
- Purpose: Track real-time capacity, allocations and constraints for hosts, clusters and cloud resources.

Key Fields
- `component`, `allocated`, `available`, `thresholds`, `alerts`.

Typical Actions
- Inspect component utilization prior to scheduling a deployment.
- Reserve capacity for critical baselines or maintenance windows.

Integration Points
- Works with `CMDB` and `Specifications` to ensure deployments are scheduled against compatible targets.
