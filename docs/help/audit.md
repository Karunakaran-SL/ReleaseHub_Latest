# Audit

Overview
- Purpose: Store activity logs, change history and events for governance and troubleshooting.

Key Fields
- `timestamp`, `actor`, `action`, `target`, `details`, `outcome`.

Typical Uses
- Investigate who approved or changed an Offline CD bundle.
- Search events related to deployments and configuration changes.

Best Practices
- Retain logs according to compliance requirements and export when needed for review.
