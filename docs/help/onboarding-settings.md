# Onboarding Settings

Overview
- Purpose: Configure organization-level defaults, team memberships, user roles and onboarding flows.

Key Fields
- `organization name`, `default roles`, `team definitions`, `user invite policy`.

Common Tasks
- Invite users and assign roles.
- Configure default approval chains and reviewers for offline deliveries.

Security
- Limit administrative roles and use audit logs to track changes to onboarding settings.
