# Fleet Management

Overview
- Purpose: Oversee and manage deployment targets and runtime resources across fleets of clusters, hypervisors and hosts.

Key Concepts
- `Deployment target groups`, `health`, `resource usage`, `drift detection`.

Typical Actions
- Group targets into fleets for coordinated operations.
- Monitor fleet health and trigger rolling updates.

Integration
- Uses CMDB data and `Resource Management` information to plan safe rollouts.
