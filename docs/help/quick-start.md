# Quick Start Guide

Overview
- Purpose: Fast orientation to ReleaseHub — onboarding, main navigation, and first tasks.

Getting Started
- Log in via the `Login` page. If you have SSO or local credentials, follow the org onboarding settings.
- Open the left-side menu and locate `Products`, `CMDB`, `Deployments`, and `Offline CD`.

First tasks
- Add a Product: go to `Products` → `Create` and fill required fields (`name`, `team`, `version`, `description`).
- Register infrastructure in CMDB: `CMDB` → `Components` → `Create` with `hostname`, `type`, `location`, `environment`.
- Create a Release baseline: `Release & Baseline` → `New Baseline` and add product versions and artifacts.

Useful Tips
- Use `Offline CD` to build and export artifacts when working in air-gapped environments.
- Use `Workflows` to automate approval gates and delivery steps.

Support
- If you hit errors, check `Audit` for events and `Onboarding Settings` for permission issues.
